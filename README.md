# 旅遊手帖 v4

一個以手機為主的多旅程規劃 App，保留原版酒紅色手繪風格，並把原本只適用於東京單一行程的資料結構改成可支援多國家、多城市與多趟旅程。

## 第一版功能

- 我的旅程：建立、瀏覽與刪除多趟旅程
- 多目的地：每趟旅程可記錄多個國家或城市
- 每日行程：依日期新增景點、餐飲、交通、住宿與活動
- 航班資訊：在總覽記錄去回程日期、航班名稱與機票雲端連結
- 護照資料：以單一、受權限保護的雲端連結保存個人護照檔案入口
- 預訂管理：航班、住宿、交通、票券、餐廳與文件連結
- 旅伴分帳：付款人、參與者、平均／自訂分攤、多幣別與建議結算
- 共同清單：待辦、行李與購物清單
- 雲端共享：沿用 Firebase，以旅程代碼上傳或加入旅程
- 舊版搬移：同一個網址若偵測到 `travel-handbook-v2`，會自動轉成一趟新版旅程
- JSON 備份：可匯出單趟旅程資料

## 檔案結構

- `index.html`：頁面骨架與表單
- `styles.css`：品牌視覺與響應式版面
- `app.js`：旅程資料、互動、分帳與 Firebase 同步

## 本機預覽

可使用任一靜態檔案伺服器開啟專案根目錄。部署到 GitHub Pages 時，三個檔案需放在同一層。

## 上線前注意

Firebase Web 設定本身會公開在瀏覽器端，真正的資料保護必須依靠 Firebase Authentication 與 Firestore Security Rules。現階段行程代碼相當於共享鑰匙，請使用難以猜測的代碼。護照雲端連結會包含在旅程資料中，務必限制雲端檔案權限、要求登入並只授權必要帳號；不要把護照檔案設為公開存取，也不要在 App 內直接保存護照號碼、信用卡或其他高敏感資料。
